## Atenção do professor: evidências

"Não basta dizer eu fiz." Para cada atividade, o documento e o vídeo devem mostrar:

1. **Planejamento:** cartão no Trello (responsável, critérios de aceitação, prazo) ou decisão registrada em documento;
2. **Execução:** commits e pull requests no GitHub, versões no Figma;
3. **Conclusão:** teste passando, tela pronta, documento aprovado ou PR revisado e integrado.
