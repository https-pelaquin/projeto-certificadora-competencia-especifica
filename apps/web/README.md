# DACOM • Gestão Financeira (Frontend)

Módulo de interface da Plataforma de Gestão de Recursos Financeiros do DACOM (UTFPR).
Desenvolvido com React, TypeScript, Vite, Tailwind CSS e shadcn/ui.

## 🚀 Como iniciar o projeto

O projeto utiliza `pnpm` como gestor de pacotes.

```bash
# Instalar dependências
pnpm install

# Rodar o servidor de desenvolvimento
pnpm dev
